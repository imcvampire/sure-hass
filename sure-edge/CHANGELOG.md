# Changelog

This addon tracks Sure prereleases. The notes that matter are upstream's:

https://github.com/we-promise/sure/releases

The addon version is `<addon_version>-<sure_version>`: the left half is this
addon's own version, the right half is the Sure prerelease it ships. Version
bumps here are almost always upstream bumps, so this file records only changes to
the addon itself.

## 0.6.0-0.7.5-alpha.8

Introduced the edge channel. Same wrapper as the stable **Sure (Finances)**
addon, pinned to the newest upstream prerelease and updated daily.
